# 🌙 SleepWell AI
### Analisis Kualitas Tidur untuk Peningkatan Produktivitas dan Well-being

SleepWell AI adalah aplikasi berbasis Artificial Intelligence yang dirancang untuk membantu pengguna memantau, menganalisis, dan meningkatkan kualitas tidur mereka melalui pendekatan berbasis data.

Proyek ini dikembangkan dalam program **Coding Camp 2026 powered by DBS Foundation** dengan tema **Healthy Lives & Well-being**.

---

## 📌 Latar Belakang

Kualitas tidur memiliki dampak besar terhadap:
- Produktivitas
- Kesehatan mental
- Energi harian
- Well-being jangka panjang

Namun, sebagian besar aplikasi sleep tracker hanya berfungsi sebagai pencatat data tanpa analisis mendalam maupun rekomendasi personal.

SleepWell AI hadir sebagai solusi yang:
- Menganalisis pola tidur pengguna
- Memprediksi kondisi kebugaran hari berikutnya
- Memberikan rekomendasi personal berbasis Machine Learning

---

## 🎯 Tujuan Proyek

- Melakukan Exploratory Data Analysis (EDA) pada dataset tidur
- Membangun model Machine Learning untuk prediksi fitness score & wellbeing index
- Mengembangkan sistem rekomendasi personalisasi
- Membuat dashboard interaktif yang mudah dipahami pengguna
- Mengintegrasikan AI model dengan web application
